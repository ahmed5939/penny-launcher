# character.glb

"Man" from the **Animated Men Pack** by Quaternius, released under
**CC0 1.0** (public domain). Downloaded from the Poly Pizza bundle
(https://poly.pizza/bundle/Animated-Men-Pack-DAC9SDgMQT) and compressed with
`compress_glb.mjs --skinned`. Walk mode uses its `Man_Idle`, `Man_Walk`,
`Man_Run` and `Man_Jump` clips, retargeted onto the hero, and falls back to
this model if the hero can't load.

# penny.glb

Power B.A.S.E. Penny (body, head and backpack) exported from the user's own
Fortnite install with `scripts/outpost-asset-recovery/extract_character.py`,
like the other game assets in this folder. © Epic Games.
